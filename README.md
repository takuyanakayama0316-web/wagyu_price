# Git Lesson

## リモートリポジトリとローカルリポジトリとはそれぞれ何でしょうか？
・自分のパソコンにあるリポジトリがローカルリポジトリ
・GITHUBなど、ネット上にあるリポジトリがリモートリポジトリ

## プッシュとマージの違いは何でしょうか？
・プッシュはローカルの変更内容をリーモートに情報を共有する
・マージは変更をしたブランチの内容を他のブランチに同じ変更を加える事ができる。

## コミットとプッシュの違い
・コミットは変更内容を記録する
・プッシュは変更した内容をリモートリポジトリに反映させる

## コミットのメッセージはどのように書いてあげるのが最適でしょうか？
・選択したファイルの中で変更した内容を第三者か見ても分かるように変更内容を書く

## ローカルでマージするフローと、プルリクエストでマージするフローの違いは何でしょうか？
・ローカルでマージするフローは、自分のパソコン上で変更内容を別のブランチに取り込む。
・プルリクエストでマージするフローは、GITHUB上で変更内容を共有し、ほかの人に確認やレビューからマージできる。
